Deux modèles XGBoost, une seule enquête

À partir des réponses du formulaire Kobo, le premier modèle décide si le ménage est éligible ; le second propose le type d'assistance qui répond à son besoin principal. Les deux ont appris les décisions de la vérification approfondie (visite à domicile et comité de ciblage).

Comment le modèle décide

  1. Il lit les {{ m.n_variables }} réponses du ménage et cherche lui-même les relations entre elles (alimentation, stratégies d'adaptation, revenu, logement, protection…).
  2. Le ménage est éligible si la probabilité atteint {{ m.seuil|pct }}.
  3. Chaque décision est expliquée réponse par réponse (valeurs SHAP) et reste revue par un superviseur.

Comment le type d'assistance est proposé

  1. Le second modèle lit les mêmes réponses, plus cinq indicateurs calculés sur ces réponses (score de consommation alimentaire, rCSI, revenu par personne, part des enfants non scolarisés, dette sur revenu).
  2. Il donne une probabilité pour chacun des {{ a.classes|length }} types d'assistance.
  3. La fiche du ménage affiche la proposition principale, les deux alternatives et les réponses qui l'expliquent.
